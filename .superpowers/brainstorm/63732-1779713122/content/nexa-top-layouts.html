A. Stacked panels

Full-width panels empilés verticalement — style btop. Dense, scannable, tout visible d'un coup. Scroll vertical si le terminal est petit.

B. Split panels

Pods à gauche, resources + events à droite — style k9s/lazydocker. Utilise mieux les terminaux larges. Navigation clavier entre panels.
